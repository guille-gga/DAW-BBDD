# 2 Modelo Entidad/Relación ( MER )

## 2.1 ¿Qué es el modelo Entidad/Relación?

Es una herramienta de referencia para la representación conceptual de problemas del mundo real. Su objetivo principal es facilitar el diseño de BD permitiendo la especificación de un esquema que representa la estructura lógica completa de una BD.

El modelo Entidad/Relación está basado en una percepción consistente de objetos básicos llamados entidades y relaciones entre estos objetos.

## 2.2 Entidades

Una entidad es una abstracción que describe un conjunto de objetos o elementos con características comunes que pueden ser diferenciados unos de otros.


1. **Entidades fuertes o regulares.**
Son aquellas que tienen existencia por sí mismas, es decir, su existencia no depende de la existencia de otras entidades.


2. **Entidades débiles**
Son aquellas cuya existencia depende de la existencia de otras instancias de entidad. 

La existencia de una instancia de una entidad débil depende de la existencia de una instancia de la entidad fuerte con la que se relaciona.

## 2.3 Atributos

**Atributo:** cada una de las propiedades o características que tiene una entidad o una relación. Los atributos representan información específica que se desea capturar y almacenar en el sistema.

### 2.3.1 Tipos de Atributos

1. **Atributos simples/atómicos o compuestos.**

-   Atributo simple o atómico: es un atributo que no puede dividirse en otras partes o atributos.
-   Atributo compuesto: son atributos que pueden ser divididos en subpartes.

2. **Atributos monovaluados o multivaluados.**

-   Atributo monovaluado: es aquél que tiene un único valor para cada ocurrencia de entidad. Un ejemplo de este tipo de atributos es el DNI.
-    Atributo multivaluado: es aquél que puede tomar diferentes valores para cada ocurrencia de entidad.

3. **Atributos obligatorios u opcionales.**

-   Atributo obligatorio: es aquél que ha de estar siempre definido para cada instancia de entidad o relación
-   Atributo opcional: es aquél que podría ser definido o no para cada instancia de la entidad.

4. **Atributos derivados/calculados o almacenados.**

-   Atributo derivado/calculado: su valor puede ser obtenido del valor o valores de otros atributos.
-   Atributo almacenado: aquellos cuyo valor se almacena directamente sin necesidad de realizar ningún cálculo. 

### 2.3.2 Claves

-   Identificador o superclave: cualquier conjunto de atributos que permite identificar de forma única a cada entidad.
-   Clave candidata: cada una de las superclaves formadas por el mínimo número de atributos posibles.
-   Clave primaria o principal: una de las claves candidatas seleccionada por el diseñador de la BD.
-   Claves alternativas: resto de claves candidatas que no han sido escogidas como clave primaria.
